# Assumptions

1. 页面是高保真交互原型，不是生产 Web App；所有数据来自仓库现有设计文档与 Mock 演示剧本，页面内标注「Mock 演算」。
2. 不引入真实平台 logo。NestWell Home US 是文档中的演示店铺，页面只出现文字店名与「美区 · 家居」描述。
3. 金额、订单数、审批数、异常数、结算差异数均取自模拟演示剧本；没有额外编造经营数据。
4. 审批按钮、异常抽屉、流程演示、命令输入是可操作的原型交互，刷新后回到初始 Mock 状态。
5. 字体使用本机可用的 Noto Serif SC / 华文宋体 / 华文仿宋 / 华文楷体，不依赖联网字体。
6. 目标视口：1440 桌面与 375 移动；页面可滚动，首屏优先呈现「一句话目标 + 流程 + 待批/异常」。
7. 设计依据：SPEC §6 主链路、§7 四闭环、§9 Agent；运营异常指南 §1/§4/§5/§6；模拟演示 §2/§3/§10/§11；Agent 统筹 §2。
