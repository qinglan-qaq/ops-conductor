## 新增流程

1. 使用 `NNNN-<slug>.md` 命名，编号递增。
2. 包含：状态、背景、决策、理由、后果、备选方案。
3. 状态使用「提议 / 已接受 / 已取代 / 已废弃」；被取代时链接新 ADR。
4. 同步更新本索引与[系统设计](../design.md)中的相关章节。
